# 泓水之戰．雙盲推演

中國戰略思想史課堂用立體兵棋。楚軍（紅）6 個步兵單位渡河北上，宋軍（藍）3 個步兵單位守國都。雙方各用手機下令，只看得到自己的部隊和已經接觸到的敵軍；老師的裁判畫面能看到全部，負責結算回合。

## 入口

- 老師：打開網頁，按「我是老師：開一局新推演」，畫面右側會出現三個 QR 碼（楚軍、宋軍、投影畫面）。
- 學生：掃描自己隊伍的 QR 碼。
- 投影幕：開「投影畫面」那個 QR 碼的網址。推演進行中只顯示回合數、哪一方已下令和戰報，不顯示兵力；結束後揭曉全部部隊位置。

## 規則摘要

- 每回合每支部隊移動一格，可分兵。
- 楚軍在渡口（河中）戰力 50%；上岸後仍為 50%（未成列），須「重新列陣」停一回合才恢復。
- 宋軍只能在北岸行動。站在河岸點可「出擊」對岸渡口（半渡而擊）。
- 宋軍打擊渡河中、未成列的楚軍時戰力 ×1.5。
- 同一路線上相距兩格以內互相看見；不同路線看不見。
- 一方行軍經過另一方所在的點位會被攔下交戰。
- 戰力比 ≥2：敗方潰滅；≥1.5：敗方折損一半並後撤；其餘：雙方各損 1，敗方後撤。
- 楚軍攻入宋營即勝；楚軍折損過半，或回合上限內未攻入，宋勝。

參數（兵力、回合上限、加成、發現距離）可在裁判畫面「參數設定」修改，重新開局時套用。

## Firebase 設定

1. 到 Firebase 主控台建立專案，啟用 Realtime Database（即時資料庫），地區選 asia-southeast1 即可。
2. 資料庫「規則」頁貼上：
   ```json
   { "rules": { "hong": { ".read": true, ".write": true } } }
   ```
3. 專案設定 → 一般 → 您的應用程式 → 新增網頁應用程式，複製設定物件（要包含 `databaseURL`）。
4. 把設定貼進 `config.js`：`window.FIREBASE_CONFIG = { ... };`

`config.js` 保持 `null` 時為單機測試模式：同一台電腦、同一個瀏覽器開多個分頁可互相同步，方便老師自己先試玩。

## 檔案

- `rules.js`：點位、路線、戰鬥與發現規則（純邏輯）
- `app.js`：立體畫面、三種角色介面、同步
- `map.png`：戰場地圖
