# 無名之戰．雙盲推演

中國戰略思想史課堂用立體兵棋。紅軍6 個步兵單位渡河北上，藍軍3 個步兵單位守國都。雙方各用手機下令，只看得到自己的部隊和已經接觸到的敵軍；老師的裁判畫面能看到全部，負責結算回合。

## 入口

- 老師：打開網頁，按「我是老師：開一局新推演」，畫面右側會出現三個 QR 碼（紅軍、藍軍、投影畫面）。
- 學生：掃描自己隊伍的 QR 碼。
- 投影幕：開「投影畫面」那個 QR 碼的網址。推演進行中只顯示回合數、哪一方已下令和戰報，不顯示兵力；結束後揭曉全部部隊位置。

## 規則摘要

- 每回合每支部隊移動一格，可分兵；同方同點自動合併。
- 紅軍在渡口（河中）戰力 50%；上岸後仍為 50%（未成列），須「重新列陣」停一回合才恢復，列陣時被攻擊會被打斷。
- 藍軍只能在北岸行動。站在河岸點可「出擊」對岸渡口（半渡而擊）。
- 藍軍打擊渡河中、未成列的紅軍時戰力 ×1.5。
- 同一路線上相距兩格以內互相看見；不同路線看不見。
- 相遇：走到同一點、對向而行、或經過對方所在點位，都會交戰；一方離開、另一方才到則追不上。
- 戰力比 ≥2：敗方潰滅；≥1.5：敗方折損一半並後撤；其餘：雙方各損 1，敗方後撤；平手各損 1，進攻方退回。敗方往遠離敵軍的方向退，退路被截則潰散。
- 紅軍攻入藍軍本陣即勝；紅軍折損過半，或回合上限內未攻入，藍軍勝。
- 聲望：藍軍國君聲望 10。藍軍主動攻擊渡河中或未成列的紅軍（出擊渡口，或走進他們所在點位），每次交戰 −2；紅軍自己衝上藍軍守住的點位不扣。

參數（兵力、回合上限、加成、發現距離、聲望扣點）在裁判畫面「參數設定」修改，按「套用並重新開局」生效；學生手機上的規則說明會跟著改。

## 測試

`node rules-test.mjs`：固定情境加三萬局隨機對局，檢查兵力守恆、敵對部隊不同處一點、不交錯而過、藍軍不過河、視野互相、資訊不外洩等。

## Firebase 設定

1. 到 Firebase 主控台建立專案，啟用 Realtime Database（即時資料庫），地區選 asia-southeast1 即可。
2. 資料庫「規則」頁貼上：
   ```json
   { "rules": { "hong": { ".read": true, ".write": true } } }
   ```
3. 專案設定 → 一般 → 您的應用程式 → 新增網頁應用程式，複製設定物件（要包含 `databaseURL`）。
4. 把設定貼進 `config.js`：`window.FIREBASE_CONFIG = { ... };`

`config.js` 保持 `null` 時為單機測試模式：同一台電腦、同一個瀏覽器開多個分頁可互相同步，方便老師自己先試玩。

## 檔案

- `rules.js`：點位、路線、戰鬥與發現規則（純邏輯）
- `world.js`、`world.css`：立體戰場（地形、河流、林木、城邑、士兵模型、鏡頭操作、油畫／全息兩種畫風），移植自《無名之戰：國君的抉擇》；檔中 `RULES.NODES` 是 16 個點位在立體地形上的座標
- `app.js`：三種角色介面、命令箭頭、同步
